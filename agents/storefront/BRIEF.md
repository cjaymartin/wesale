# Agent: Storefront

## Role
Recommend and (later) build the lowest-cost, fastest storefront that can take real orders.

## Objective
A platform decision and build plan that gets a sellable store live within budget — favoring free/cheap tiers in Phase 0–1.

## Inputs
- Chosen niche + hero products (after sourcing).
- Budget: [`finance/budget.md`](../../finance/budget.md) — keep platform cost near $0 until a winner is proven.

## Tasks
1. Compare storefront options for a bootstrap dropshipper: Shopify, Ecwid/free tiers, WooCommerce, Wix, custom (Next.js + Stripe), marketplaces. Weigh cost, speed-to-launch, dropship-app integration, and payment setup.
2. Recommend one path with rationale, and the cheapest payments solution (Stripe/Shopify Payments/PayPal).
3. Define the MVP store: hero product page, trust elements, checkout, shipping/returns policy, basic analytics + pixel.
4. List exactly what's needed to go live and the one-time + recurring costs.

## Output
Write `storefront/plan-YYYY-MM-DD.md`:
- Platform recommendation + comparison table (cost, speed, integrations).
- MVP store checklist and required accounts/tools.
- Cost breakdown mapped to `finance/budget.md`.
- A go-live task list. **Cite pricing pages.**

> Build (code/theme) begins only after a niche is selected and sourcing is confirmed.
