# Marketing — execution playbooks

Step-by-step guides to drive traffic to the NoseyMutt store. Strategy/analysis lives in [`../research/marketing/`](../research/marketing/); these are the *do-this-now* playbooks.

| File | What it is | Cost |
|---|---|---|
| [`meta-ads-setup-walkthrough.md`](meta-ads-setup-walkthrough.md) | From-zero Meta account → Page, Business portfolio, ad account, Pixel, and the exact $90 Add-to-Cart test campaign. | ~$90 test (acct setup $0) |
| [`cheaper-channels.md`](cheaper-channels.md) | The cheap/free engine: Pinterest, organic TikTok/Reels, influencer gifting, community + email/SMS. One weekly filming session feeds all of them. | ~$0 (optional $30–50 Pinterest test) |
| [`seo-strategy.md`](seo-strategy.md) | SEO + blog content engine: keyword map, on-page/technical SEO for Shopify, 16-post blog calendar, free backlinks. | $0 (2–3 hrs/week) |

## Recommended sequencing (lowest cost first)
1. **Cheap channels + SEO first** — start the organic video + Pinterest + email engine and the blog *before* spending on ads. These lower blended CAC, which the channel analysis says is the only way the $500 math closes.
2. **Then the paid Meta test** — once the store is live with the AOV-lifting bundle + honest shipping ETAs, run the $90 ATC test as a *scalable* validation, not the primary traffic source.

> ⚠️ Hard rule across every channel: **no health/medical claims** (boredom/enrichment framing only) — protects ad accounts and listings. See `storefront/brand.md`.
