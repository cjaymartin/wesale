# NoseyMutt — Store Setup & Go-Live Checklist

Decided stack (from research): **Shopify Basic (promo) + Shopify Payments + DSers-free/CJ** for fulfillment. ~$13 to launch, ~$0/mo ongoing automation. No paid "done-for-you" builder.

Work top → bottom. ⏱️ = rough time. 💲 = spend (log every one in `finance/budget.md`).

## 0. Pre-flight (brand + accounts)
- [ ] 💲 USPTO quick search for "NoseyMutt" (free) → if clear, 💲 register `noseymutt.com` (~$10–12). ⏱️15m
- [ ] Claim @noseymutt on Instagram + TikTok; create a Facebook Page (needed for Meta ads later). ⏱️20m
- [ ] Create a Gmail/business email + set hello@noseymutt.com forwarding at the registrar. ⏱️10m

## 1. Shopify account (⏱️30m · 💲~$1–3 over 3 mo on promo)
- [ ] Start Shopify free trial → take the **$1/mo-for-3-months** promo on the **Basic** plan.
- [ ] Store name: NoseyMutt. Connect `noseymutt.com` (Settings → Domains).
- [ ] Install the free **Dawn** theme. Set brand colors + fonts from `brand.md`.
- [ ] Set up a simple logo (Hatchful/Canva free, or 💲~$15 Fiverr wordmark — optional).

## 2. Payments (⏱️15m)
- [ ] Activate **Shopify Payments** (2.9% + 30¢, no extra platform fee). Add bank details.
- [ ] Add **PayPal Express** as secondary (lifts conversion).
- [ ] ⚠️ Do NOT use a third-party gateway on Basic — it triggers an extra 2% Shopify fee.

## 3. Fulfillment automation (⏱️45m · 💲$0)
- [ ] Create a **CJdropshipping** account (you have prior CJ experience). Connect CJ ↔ Shopify (CJ app or **DSers**, both free).
- [ ] Import the SKUs. For the **Starter Kit**, build it from **one CJ supplier / same warehouse (ideally CJ US-WH)** so it ships as one parcel.
- [ ] Set **auto-order / auto-fulfill** + tracking sync ON (this is the "runs itself" layer — order routing + tracking only; ads/CS/returns stay manual).
- [ ] Set pricing rules to the retail in `catalog.md` (don't rely on auto-markup).

## 4. Products (⏱️1–2h · paste from `catalog.md`)
- [ ] Create the 7 products with the provided titles, descriptions, bullets, SEO, variants, prices.
- [ ] Build collections: **The Enrichment Collection**, **Bundles & Kits**, **Refills**.
- [ ] Use clean supplier images now; **swap in your own sample-order photos/video** once it arrives (own media converts far better + is ad-safe).
- [ ] Set the **Refill 3-Pack** as a checkout **order-bump** (free app: e.g. "Ultimate/Releasit upsell" free tier, or Shopify's native cart upsell).

## 5. Pages & navigation (⏱️45m · paste from `pages/`)
- [ ] Create pages: Shipping, Returns, FAQ, About, Contact.
- [ ] Generate Privacy / Terms / Refund under **Settings → Policies** (see `pages/legal-contact.md`).
- [ ] Header nav: Home · Shop (Enrichment Collection) · Starter Kit · About. Footer: all policies + contact + socials.
- [ ] Build the homepage sections per `pages/homepage.md`.

## 6. Shipping & checkout config (⏱️30m)
- [ ] Shipping: **Free over $35**, else flat $4.95 (matches the shipping policy). US-only zone to start.
- [ ] Turn ON abandoned-cart email (Shopify native, free) — recovers lost orders.
- [ ] Test checkout in test mode, then place one real $0.50–level test or use Shopify's Bogus Gateway.

## 7. Analytics & pixels (⏱️30m) — do BEFORE any traffic
- [ ] Install **Meta Pixel** (Facebook & Instagram sales channel) — needed for the Add-to-Cart-optimized ad test in the marketing plan.
- [ ] Install **Google Analytics 4** (free).
- [ ] Add a **cookie-consent banner** (free app) — required for pixels.
- [ ] Verify Add-to-Cart + Purchase events fire (Meta Events Manager test).

## 8. Trust & polish (⏱️30m)
- [ ] Free **reviews app** (e.g. Judge.me free / Shopify Product Reviews) — seed honestly with sample-order photos; never fabricate reviews.
- [ ] Add trust badges (secure checkout, 30-day guarantee, free shipping) to product pages.
- [ ] Favicon + social share image.

## 9. Pre-launch QA
- [ ] Every product page: price, variants, images, Add to Cart, shipping ETA all correct.
- [ ] Mobile check (most traffic is mobile).
- [ ] Policies linked in footer; contact email works.
- [ ] One full test purchase end-to-end (incl. the order-bump).
- [ ] Remove the password page → **store is LIVE**.

## 10. First-order loop (after the sample order arrives)
- [ ] Place the **CJ sample order through your own store** (the CEO's plan) → confirms the full customer flow + real landed cost + ETA.
- [ ] Replace placeholder ETAs/photos with the confirmed real ones.
- [ ] Hand the green-lit store to the **marketing launch test** (`research/marketing/channel-plan-2026-06-15.md`): $90 ATC-optimized creative test → scale rule.
