# Storefront Plan — wesale (2026-06-15)

**Author:** Storefront agent · **Budget context:** [`finance/budget.md`](../finance/budget.md) — $500 hard cap, keep platform cost near $0 until a winner is proven · **Market:** US

---

## 1. TL;DR

- **Recommended platform:** **Shopify Basic**, entered via the **3-day free trial → $1/mo for 3 months** promo. This buys a fully featured, conversion-optimized store with native dropship-app integration for ~$3 across the entire validation window.
- **Recommended payments:** **Shopify Payments** (2.9% + 30¢, no extra platform transaction fee). Add **PayPal** as a secondary express option (Shopify treats native PayPal as accelerated checkout with no Shopify markup). This is also the cheapest viable option because using any *third-party* gateway on Basic incurs an extra **2%** Shopify fee.
- **Dropship app:** **DSers (Free plan)** for AliExpress, or **CJ Dropshipping (free, pay-per-order)** for better US shipping times. Both $0/mo.
- **Estimated go-live cost:** **~$13** ( $3 Shopify promo over 3 months + ~$10 domain ). All ad/sample spend is separate and governed by the budget ledger.

## 3. Recommendation + Rationale

**Go with Shopify Basic on the $1/mo-for-3-months promo, paired with Shopify Payments (+ PayPal).**

Why this path wins for a $500 bootstrap dropshipper:

1. **Cost during validation is effectively $0.** The 3-day free trial plus $1/mo for 3 months ([shopify.com/pricing](https://www.shopify.com/pricing)) means the platform costs ~$3 across the exact window we need to prove or kill a product. That preserves nearly the entire $500 for the things that actually generate signal: ad tests and product samples.
2. **Zero platform transaction fee with Shopify Payments.** Basic adds a 2% fee *only* if you use an outside gateway. Using native Shopify Payments avoids that entirely — so the cheapest payments solution and the best-converting one are the same choice. (Building custom on Stripe saves the 2% too, but the multi-week build cost dwarfs any fee savings at validation volumes.)
3. **Fastest credible speed-to-launch.** A themed, trust-element-complete store is live in hours, versus 3–7 days for WooCommerce or weeks for a custom Next.js build.
4. **Best dropship-app integration.** DSers, CJ, Zendrop, and Spocket are all native one-click Shopify apps with free tiers, so order routing to the supplier is automated rather than hand-glued.
5. **Clean exit / scale path.** If a winner proves out, we simply let the store roll to $29/mo (annual) Basic — no migration, no replatforming.

**Trade-off accepted:** after the 3-month promo, Shopify Basic is $29–39/mo, more than Ecwid Starter ($5) or a bare custom build ($0). That is fine: by then we will either have a proven winner (the $29 is trivially covered by margin) or have killed the test before the promo ends. ⚠ Decision checkpoint: re-evaluate platform at end of promo (≈ 2026-09-15) before the first full-price charge.

**Cheapest viable payments solution:** Shopify Payments (2.9% + 30¢, no platform surcharge) as primary; PayPal as secondary express button. Avoid third-party-only gateways on Basic (they trigger the 2% fee).

**Marketplace note:** eBay (free to list ≤250 items) is worth running in parallel as a zero-cost demand probe for the same hero product — but it is a *test channel*, not the storefront, because of its ~13.6%+$0.40 take rate and lack of pixel/funnel control.

## 4. MVP Store Checklist

Build begins only after niche + hero product + sourcing are confirmed (per brief). The MVP store must have:

**Storefront / product**
- [ ] Hero product page: clear value prop, benefit-led headline, 5–8 quality images + short video if available, concise bullet benefits, price, single prominent Add-to-Cart / Buy-Now.
- [ ] Social proof: 5–15 reviews (imported or seeded honestly), star rating widget, UGC photos.
- [ ] Trust elements: secure-checkout badges, "ships from / delivery estimate," money-back guarantee line, visible contact method.
- [ ] FAQ block (shipping time, returns, sizing/specs).

**Policies (required for ad-platform approval + Shopify Payments)**
- [ ] Shipping policy (realistic dropship transit times, US-focused).
- [ ] Returns / refund policy.
- [ ] Privacy policy + Terms of Service (Shopify auto-generates templates).
- [ ] Contact page with a real support email on the domain.

**Checkout / payments**
- [ ] Shopify Payments activated (business/EIN or SSN sole-prop, bank account).
- [ ] PayPal Express enabled as secondary.
- [ ] Abandoned-cart email enabled (native, free).
- [ ] Test order placed end-to-end and refunded.

**Analytics / pixels**
- [ ] Shopify native analytics on.
- [ ] Meta Pixel + Conversions API.
- [ ] Google Analytics 4 (+ Google Ads tag if running Google).
- [ ] TikTok Pixel if TikTok is a test channel.

**Fulfillment plumbing**
- [ ] DSers (free) or CJ (free) connected; hero product mapped to supplier.
- [ ] Order-routing test: place test order → confirm it flows to supplier draft.

**Required accounts/tools (all free to open):** Shopify, domain registrar (Cloudflare or Namecheap), Shopify Payments, PayPal Business, DSers or CJ, Meta Business Manager, Google Analytics, business email (forwarding via registrar or Shopify).

## 6. Go-Live Task List

**Phase A — Accounts (do first, all free)**
1. Register domain (Cloudflare or Namecheap promo).
2. Start Shopify 3-day free trial; opt into $1/mo×3 promo; pick Basic.
3. Open PayPal Business; gather bank + tax ID for Shopify Payments.

**Phase B — Build (after hero product confirmed)**
4. Install free theme (Dawn/Horizon); set brand name, logo, colors, favicon.
5. Connect domain to Shopify.
6. Build hero product page (copy, images, price, reviews, trust badges).
7. Add Home, FAQ, Contact; generate Shipping, Returns, Privacy, ToS policies.
8. Configure US shipping zones + realistic delivery estimates.

**Phase C — Payments & fulfillment**
9. Activate Shopify Payments; enable PayPal Express; disable third-party-only gateways (avoid 2% fee).
10. Install DSers or CJ (free); map hero product to supplier; set pricing/margin rules.
11. Enable abandoned-cart recovery email.

**Phase D — Analytics**
12. Install Meta Pixel + Conversions API; GA4; TikTok Pixel (if used); Google Ads tag (if used).

**Phase E — QA & launch**
13. Place a real test order end-to-end; confirm it routes to supplier; refund it.
14. Mobile + desktop QA (load speed, checkout, broken links, policy links).
15. Remove store password; go live.
16. (Parallel, optional, $0) List hero product on eBay as a demand probe.

**Phase F — Guardrails**
17. Log every spend in `finance/budget.md` before purchase.
18. Calendar reminder ≈ 2026-09-15 to decide annual Basic vs. pause before promo ends.
19. Apply the budget kill rule: if cumulative ad spend on a test > 1.5× gross margin it generated, kill it.
